# Vidéo « Review Maker crée ton site internet »

Montage Remotion, 1080×1920 à 60 i/s, 26 s, sans voix off, dans la DA Review Maker (Poppins, bleu marine #0E1A3A, bleu de la marque #4166B0, fond clair #F4F7FC).

- `src/SitesWeb.tsx` : la timeline (titres, caméra, transitions, sons)
- `src/Site.tsx` : le site d'exemple « Ton commerce » (ordinateur + mobile)
- `src/components.tsx` : fond, titres animés, étoiles, pastilles
- `scripts/make_sfx.py` : génère les effets sonores de `public/sfx`

```
npm install
npm run studio   # aperçu
npm run render   # → out/ReviewMaker-SitesWeb.mp4
```
